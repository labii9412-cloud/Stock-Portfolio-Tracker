# Stock Portfolio Tracker

A simple Python-based Stock Portfolio Tracker that allows users to enter stocks and quantities, calculate their total investment value, display a portfolio summary, and save the results to a text file.

## Features

* Enter stock names and quantities
* Calculate investment value
* Display portfolio summary
* Save results to a text file
* Handles invalid stock names and quantities

## Technologies Used

* Python
* Dictionary
* Functions
* Basic Arithmetic
* File Handling

## How to Run

Run the following command:

```bash
python portfolio.py
```

## Supported Stocks

* AAPL
* TSLA
* GOOGL
* MSFT
* AMZN
